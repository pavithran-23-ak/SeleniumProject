# 🧪 SeleniumForBeginners

Welcome to **SeleniumForBeginners** — a hands-on automation testing project built to demonstrate core Selenium WebDriver capabilities using Java. This repository showcases practical test scripts and exception handling techniques that are essential for real-world web application testing.

## 🚀 Project Overview

This project is part of my transition from healthcare BPO to IT automation testing. It includes a variety of test cases and suites designed to validate login functionality, handle common Selenium exceptions, and execute both smoke and regression testing workflows.

## ✅ What’s Included

- **Login Tests**
    - ✔️ Positive Login Test
    - ❌ Negative Login Test

- **Exception Handling Tests**
    - 🔍 `NoSuchElementException`
    - 🚫 `ElementNotInteractableException`
    - ⚠️ `InvalidElementStateException`
    - 🔄 `StaleElementReferenceException`
    - ⏳ `TimeoutException`

- **Test Suites**
    - 🔥 Smoke Test Suite
    - 🧪 Full Regression Test Suite

## 🛠 Tech Stack

- **Language**: Java
- **Frameworks**: Selenium WebDriver, TestNG
- **Build Tool**: Maven
- **IDE**: IntelliJ IDEA / Eclipse
- **Version Control**: Git & GitHub
